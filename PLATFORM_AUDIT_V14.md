# Binso Admin v14 – Platform Audit

## Korrigiert
- A4-Dokumentvorschau bleibt auf allen Viewports in echter A4-Geometrie; nur die gesamte Seite wird skaliert.
- Keine Preis-/Positionsspalten werden in der PDF-Vorschau auf Mobile ausgeblendet.
- Dokumentlogo ist transparent und auf dem weissen PDF schwarz.
- Sheets haben sticky Header/Aktionsleiste, internes Scrollen und Safe-Area-Abstände.
- Mobile/PWA-Inputs sind 16 px und mindestens 44 px hoch.
- Mobile Navigation, Command Dialog und Popover sind auf 100dvh begrenzt und scrollbar.
- Pille hat eine symmetrische 64-px-Center-Aktion.
- Sales/Zahlungen verwenden auf Mobile lesbare flache Zeilen.

## Wichtig
Statische Quellcodeprüfung kann reale Browser-/OS-Renderingtests nicht vollständig ersetzen. Der GitHub Build und eine visuelle Smoke-Prüfung auf Safari iOS/PWA, Chrome Android, Edge Windows und Desktop bleiben Release-Gates.
