# Binso Admin v8 – Enterprise Polish

Kumulativer Stand auf Basis von v7.

## v8 UI/UX-Änderungen

- Desktop-Header kompakter; `Neu` ist nur noch eine unaufdringliche Plus-Aktion.
- Desktop Quick Create erscheint als kleines flaches Command-Popover statt grossem Sheet/Card.
- Page-Header-Aktionen sind kompakte Toolbar-Aktionen statt dominanter Primärbuttons.
- Sidebar aktiver Eintrag flacher mit schmalem Aktiv-Indikator.
- Schnellere Route-Transitions ohne Blur.
- Native Font-Rendering-Einstellungen; keine künstliche Glättung.
- Dezente Desktop-Scrollbars und stabileres Scrollverhalten.
- Mobile/PWA-Pille kleiner, symmetrischer, ruhigere Umrandung und feinere Separatoren.
- iOS Auto-Zoom bei Inputs wird über 16px Inputs verhindert.
- Mobile Bottom Sheets scrollen intern und ziehen die Seite im Hintergrund nicht mit.
- Formulare, Dialoge und Listen sind flacher und weniger card-lastig.

## Deployment

Bestehende `package-lock.json` im Repository behalten. Alle übrigen v8-Dateien können über den bestehenden Stand gelegt werden.
