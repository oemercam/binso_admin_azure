# Navigation Inventory v1.8.0

## Primäre Mobile/PWA Navigation

- Start → `/dashboard`
- Kunden → `/kunden`
- Neu → Quick Create Bottom Sheet
- Zeit → `/zeiterfassung`
- Profil → Profil/Konto Bottom Sheet

## Vollständige Module

Das Grid-Symbol öffnet `/module`. Dort stehen die freigegebenen Module nach Bereichen gruppiert zur Verfügung. Es gibt keine zweite permanente globale Navigation.

## Detail/Create Navigation

Detail- und Create/Edit-Seiten verwenden auf Mobile eine kompakte Back-Topbar. Desktop behält seine bestehende Navigation unverändert.

## Neue Route

`/module` ist eine authentifizierte Workspace-Route für die Mobile/PWA-Modulübersicht.
