# Mobile/PWA KPI standard — V36

Numeric summary areas use one consistent geometry:

## Three values
Used by:
- owner dashboard
- employee dashboard
- customer detail
- order detail

Rules:
- exactly three equal columns
- one row
- equal horizontal padding
- vertical separators only between columns
- label and value stay on one line
- secondary detail text hidden on Mobile/PWA
- tabular numerals for stable alignment

## Four values
Used by:
- finance dashboard
- Finanzen
- Buchhaltung

Rules:
- balanced 2x2 grid on Mobile/PWA
- equal cell dimensions
- consistent row/column separators
- secondary detail text hidden

## Two values
Used by:
- Zeiterfassung

Rules:
- two equal columns
- progress indicator below both columns
- secondary detail text hidden on Mobile/PWA

Desktop remains unchanged.
