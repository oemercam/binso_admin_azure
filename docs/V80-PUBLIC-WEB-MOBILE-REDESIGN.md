# V80 Public Web and Mobile Redesign

V80 replaces the accumulated public marketing-page layout with one deliberately scoped public system while leaving the authenticated customer application unchanged.

## Design direction

- persistent desktop navigation with brand, product navigation, login and one primary CTA
- simple mobile header with a full-height menu instead of stacked legacy dropdown rules
- balanced text/image split sections; product screenshots never dominate the viewport
- desktop screenshots are intentionally reused on narrow marketing sections so the complete application view remains visible instead of switching to very tall mobile screenshots
- alternating left/right feature composition on desktop; compact stacked composition on mobile
- compact, structured footer across desktop, tablet and phone sizes
- restrained typography, borders, spacing and shadows

The direction is inspired by established SaaS interaction patterns such as consistent navigation, calm hierarchy, progressive disclosure and mobile-first access. It does not copy another company's visual identity.

## Scope

Public shell, landing page and feature presentation only. Authenticated customer and operator application surfaces are not redesigned in V80.
