# V81 – Public Mockup Implementation

## Scope

- Public website only: landing page, public navigation, public footer and public feature presentation.
- Authenticated customer application and dashboard styling remain unchanged.
- Public styles stay isolated under `public-site-v80` and `v80-*` selectors.

## Visual system

- Compact desktop header with Funktionen, Preise, FAQ, Kontakt, Kundenlogin, Admin-Zugang and the primary trial CTA.
- Hero with copy on the left and the real dashboard screenshot on the right.
- Alternating compact product rows using real Binso One screenshots with `object-fit: contain`.
- Mobile uses a clear header, fullscreen menu and stacked text/screenshot sections.
- Product screenshots use the desktop captures on mobile too, avoiding very tall multi-viewport screenshots.
- Black/white foundation with Binso blue as the restrained primary accent.

## Truthful public content

The mockup contains example customer logos, quotes and third-party integration brands. These were not copied into production because there is no verified project evidence that they are customers, testimonials or active integrations. The public page uses a truthful trust section and an integration concept instead.

## Trial period

The product trial configuration was aligned to 30 days so the public CTA and the actual onboarding entitlement remain consistent.
