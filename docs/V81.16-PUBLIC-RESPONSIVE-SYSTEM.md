# V81.16 Public Responsive System

V81.16 consolidates the active public/pre-app visual rules into one canonical layer loaded after the legacy marketing compatibility CSS.

## Central ownership
- Public geometry, type scale, gutters, control height, radii and colours are defined as `--public-*` tokens in `app/styles/tokens.css`.
- `app/styles/public-responsive-system.css` is imported last and owns the current public responsive behaviour.
- Header/footer navigation remains data-driven from `lib/config/public-site.ts`.
- Authenticated application layout is not changed by this version.

## Responsive policy
- Fluid gutters from 16 to 28 px.
- Mobile/tablet navigation through 960 px to avoid cramped tablet headers.
- Representative QA viewports: 320, 360, 390, 430, 768, 834, 1024, 1440 and 1920 px.
- Public H1 uses one fluid scale from 34 to 50 px.
- Public forms use at least 44 px controls and 16 px input text to avoid iOS zoom.
- PWA keeps safe-area handling for notch/home-indicator environments.

## Visual policy
- One font stack (`--font-sans`).
- Shared shell/content/reading widths.
- Shared card radius, border and shadow.
- Consistent section spacing, CTA height and mobile stacking.
- Footer remains compact but readable and left-aligned.
