# V81.16.3 — Responsive regression fixes

This release fixes the three issues found by the full Playwright viewport matrix after V81.16.2.

- Adjusts the canonical fluid public H1 token so 390px widths no longer land at 35.8px.
- Restores the intended closed state for the body-ported mobile/tablet navigation panel; only `.is-open` / `aria-hidden="false"` displays the panel.
- Gives the exhaustive 9-viewport × 6-route matrix its own 180s timeout instead of Playwright's 30s default.
- Keeps the V81.16 canonical responsive layer as the single public responsive owner.

No authenticated application UI or production authentication flow is changed.
