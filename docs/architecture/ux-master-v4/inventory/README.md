# Global Action System V3 – Quellinventur

84 Routen, 6252 Aktionsvorkommen inklusive gemeinsam erreichbarer Owner. Erzeugt aus dem aktuellen Code, ohne geplante Funktionen aus Konzeptpapieren zu erfinden.

Die Matrix enthält Quellbeleg, Auslöser, Handler/Ziel, vorgeschlagenen Aktionsort und vorhandene Bedingungsausdrücke. Bedingungen sind Owner-Kontext, kein Beweis der individuellen serverseitigen Freigabe. Dynamische Props, konkrete Rollen/Tarife/Status und verschachtelte Entitäten müssen einzeln geprüft werden; unbekannte Werte bleiben ausdrücklich offen. Das Inventar ist vollständig über gefundene Seiten und statisch erreichbare Owner, keine vollständige fachliche oder visuelle Abnahme. Öffentliche Routen sind zur Abgrenzung enthalten.

V26: Nur tatsächlich vorhandener Code ist aufgeführt. Geplante V26-Funktionen werden nicht als implementiert gewertet.
