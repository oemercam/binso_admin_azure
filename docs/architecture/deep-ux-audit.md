Base: main `a6c07b233cd9dc71eeee0beacbb0fa1d8c67b79b`; existing PR #222 reused. Original PR head `e6b180dd8e8afda2f0bcbb1d32769d87ce07ab00`.

## Evidence and limits

- Source inventory: 70 page routes, ancestor layouts and global components, 121 AST-confirmed JSX definitions, local export aliases, owning JSX props, CSS import order and 2,590 CSS rule records. Shared props are recorded once per component rather than duplicated per route.
- Browser evidence records visible DOM classes/inline declarations, geometry, computed layout properties and active matching CSSOM rules. Matching rules are cascade candidates; computed values are the browser result. Inherited rules and every permission/status combination are not exhaustively traced.
- Read-only fixture APIs isolate all browser writes. Financial/RLS and real renderer tests are separate. These are not production data or physical-device certification.
- 465 repeated selector/context candidates are recorded, not declared bugs. No !important declarations. Only confirmed dependencies were removed.
- Retired invoice/offer HTML templates had no runtime consumer. The remaining subscription demo HTML paper was migrated before its styles were removed. Actual server PDF rendering and payment data are unchanged.
- Prior PR failure: synchronous effect state reset failed lint; old browser expectation required a second simultaneous canvas. Both causes are corrected, not bypassed.
