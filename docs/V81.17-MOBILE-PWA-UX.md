# V81.17 Mobile/PWA UX

V81.17 consolidates the Mobile/PWA behaviour requested for Binso One into one final CSS ownership layer and removes the previous scroll-to-hide header mechanism.

## Global changes

- White `theme-color`, white manifest backgrounds and `viewport-fit=cover` remain canonical.
- Mobile browser and installed PWA force a light system surface so iOS safe areas cannot become black from OS dark mode.
- Authenticated and public headers are sticky and never hide while scrolling.
- Permanent header blur is disabled in the canonical layer.
- Safe-area ownership covers header, public mobile menu, bottom pill, sheets, dialogs, fullscreen overlays and toast regions.
- Native vertical document scrolling remains the default. The VisualViewport scroll listener was removed to avoid React state updates during page scroll.
- Browser-back scroll restoration remains requestAnimationFrame/passive-event based; normal route changes start at the top.
- Route motion is limited to 160 ms opacity/translateY and disabled for reduced motion.
- Installed PWA cold start gets a non-blocking white CSS splash with a short Binso logo animation. It does not replay on client-side route transitions.
- Product screenshot markup now declares intrinsic dimensions for desktop/mobile sources to reduce layout shift.
- `.env.example` is retained in the full-project ZIP.

## Removed old logic

- `hooks/use-header-visibility.ts`
- `lib/browser/window-scroll.ts` (unused global scroll subscriber)
- AppShell `is-hidden` header switching
- VisualViewport `scroll` subscription in the environment provider
