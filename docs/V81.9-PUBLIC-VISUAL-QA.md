# V81.9 Public Visual QA

V81.9 is the final visual-standardisation pass for the complete public and pre-app experience. It does not change authenticated `app/(app)` product screens.

Checked and standardised areas:
- one public font stack, H1/H2/body scale and consistent line-height/letter-spacing;
- desktop and mobile header/navigation geometry and touch targets;
- consistent public content widths, gutters and section rhythm;
- feature/process screenshots with a stable, compact frame instead of tall page captures;
- pricing cards, FAQ accordions, contact/help forms, security flow and status cards;
- sign-in, admin access, registration and demo step presentation;
- legal/help reading width and paragraph/heading rhythm;
- footer hierarchy, link sizes and mobile stacking;
- 320, 360, 390/430, tablet, desktop and installed-PWA safe-area handling.

Automated protection:
- all public routes are exercised at the existing responsive viewport matrix;
- V81.9 adds targeted typography, demo-step, security-flow and image-frame assertions;
- `pnpm run v819:check` validates that the public visual rules and required marketing assets remain present;
- CI now executes the V81.9 check before producing a production artifact.
