# Incident Runbook
SEV1 critical widespread outage/major security incident; SEV2 major degradation; SEV3 limited impact; SEV4 minor. SEV1/2 roles: Incident Lead, Technical Lead, Communications, Security/Privacy as needed. Timeline: detection, acknowledgement, mitigation, recovery, resolution, root cause, actions. Customer states: Investigating, Identified, Monitoring, Resolved.
