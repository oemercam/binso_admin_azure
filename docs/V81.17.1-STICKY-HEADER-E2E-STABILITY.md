# V81.17.1 — Sticky Header and E2E Stability

- Removes horizontal overflow clipping from `.public-site-v80`, because an overflow-clipped ancestor can prevent viewport-sticky descendants from sticking correctly.
- Keeps horizontal clipping at the root/body viewport boundary instead.
- Removes transform from the persistent `.route-stage` wrapper; page transition is opacity-only so sticky/fixed descendants keep normal viewport containment.
- Raises the older broad V81.13 public visual matrix timeout to 120 seconds. This test performs 36 full navigations plus layout scans and is not a 30-second unit test.
- Adds runtime E2E assertions for public-shell overflow containment and route-stage transform state.
