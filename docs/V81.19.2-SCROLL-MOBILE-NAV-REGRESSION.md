# V81.19.2 — Scroll ownership and mobile navigation regression

V81.19.2 addresses two regressions exposed by the full Playwright suite after the V81.18/V81.19 product-simplicity changes.

- The simplified mobile bottom navigation is `.mobile-primary-nav`; legacy E2E selectors that still waited for `.mobile-pill` now target the active navigation component and its current accessibility label `Hauptnavigation`.
- Vertical scrolling is owned by the document root (`html`) instead of `body`. Keeping `body` at `overflow: visible` prevents it from becoming a non-scrolling sticky ancestor while `window.scrollTo` scrolls the document element. This restores the public and authenticated sticky-header contract without JavaScript scroll handlers.
- GitHub Actions now runs V81.19.1 and V81.19.2 product checks in the quality job.

No subscription entitlements or V81.18 product-simplicity behaviour are changed.
