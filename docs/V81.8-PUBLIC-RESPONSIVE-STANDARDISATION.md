# V81.8 Public Responsive Standardisation

V81.8 standardises every public and pre-app page against the V81.6/V81.7 landing-page visual system.

- One H1 scale and weight across landing, features, pricing, FAQ, contact, flow, security, status, help, legal, sign-in, admin access and registration.
- All public page widths align to the 980 px mockup content grid.
- Registration/demo steps are rebuilt for compact mobile readability without clipping or crowded typography.
- Tablet and mobile layouts are normalised at 820, 560 and 360 px.
- Standalone/PWA mode respects top and bottom safe areas.
- E2E coverage now includes all public routes, the demo registration flow, and title-scale consistency.
- Authenticated app visuals are unchanged.
