# V81.19.3 – Optional source-root CI compatibility

The architecture check no longer assumes that optional source-root directories exist after a Git checkout.

`hooks/` became empty after the V81.17 cleanup. Empty directories are present in a local extracted ZIP but are not tracked by Git, so GitHub Actions legitimately checks out the repository without `hooks/`. The architecture scanner now skips missing optional source roots instead of failing with `ENOENT`.

No product, subscription, navigation or runtime behaviour changed in this patch.
