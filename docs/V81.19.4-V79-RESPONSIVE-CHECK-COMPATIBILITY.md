# V81.19.4 – V79 responsive check compatibility

The legacy V79 foundation check still required the old `.mobile-pill` selector inside the responsive E2E suite. V81.18 replaced that navigation surface with `.mobile-primary-nav`, so GitHub Actions failed even though the current E2E suite passed.

V81.19.4 updates the legacy invariant to accept the current canonical mobile navigation selector while retaining compatibility with older branches. No runtime, subscription, entitlement, navigation, or business logic is changed.
