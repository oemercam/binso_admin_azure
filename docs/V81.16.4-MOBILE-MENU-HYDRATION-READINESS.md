# V81.16.4 – Mobile menu hydration readiness

This release hardens the public mobile/tablet navigation against clicks that occur before React hydration has attached the menu event handlers.

- The menu trigger is disabled until the client is hydrated.
- A `data-hydrated` state is exposed for browser QA.
- Playwright waits for the trigger to be enabled and hydrated before interacting with it.
- No production navigation structure or authenticated application UI is changed.
