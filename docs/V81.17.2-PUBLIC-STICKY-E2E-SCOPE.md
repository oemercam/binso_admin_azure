# V81.17.2 — Public sticky-header E2E scope

The V81.17 sticky-header E2E test waited for `.route-stage` on `/`, but that wrapper exists only in the authenticated `(app)` layout. The wait consumed the full timeout and masked the actual public-header assertion.

V81.17.2 scopes the test to the real architecture:

- public `/`: validate white surface, public sticky header, public overflow ownership and absence of `.route-stage`
- authenticated `/dashboard`: validate `.route-stage` is present and transform-free, then validate sticky app header
- no production UI behavior is changed by this patch
- the CI workflow runs the new regression guard
