# V81.4 Mobile Exact Mockup

V81.4 aligns the complete public mobile experience with the approved Binso One mobile mockup while keeping the authenticated application untouched.

Key points:
- mobile header uses the same compact brand / hamburger composition as the mockup;
- landing page always renders copy before the related product screenshot;
- real desktop product screenshots remain fully visible and compact on mobile, matching the reference composition;
- hero CTAs are full width and the dashboard is presented in the compact laptop frame;
- feature, integrations, references, testimonials, pricing CTA and footer use the same section rhythm and spacing as the mobile reference;
- public detail pages and pre-app/auth pages share the same mobile spacing, typography and screenshot treatment;
- breakpoints are explicitly tuned for 320, 375/390 and 430 px widths;
- no authenticated `app/(app)` visual styles are changed.
