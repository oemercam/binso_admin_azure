# Binso One v0.6.0 – I18N, Fehler, Bestätigungen und Validierung

## Sprachen
- Deutsch
- Englisch
- Französisch
- Italienisch

Die Sprache wird lokal pro Browser gespeichert. Eine zentrale Locale-Schicht übersetzt Navigation, Marketing, Auth, Fehlerseiten, Formulare, Aktionen, Status und dynamisch nachgeladene UI-Texte.

## Systemseiten
- 404 Not Found
- Route Error / 500
- Global Error
- Loading
- 403 Forbidden
- 503 Maintenance
- Offline

## Bestätigungen
- Onboarding abbrechen
- Formular mit ungespeicherten Änderungen verlassen
- Datensatz löschen
- Demo-Daten zurücksetzen
- Browser-Tab bei ungespeicherten Formularänderungen schliessen
