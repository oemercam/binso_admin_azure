# Account/Profile UX v0.8.1

## Topbar
Das bisherige Mischmenü aus Firma, Testmandant, Testbenutzern und Abmelden wurde entfernt.

Neu:
- aktueller Benutzer + Firma im kompakten Trigger
- Profilkopf mit Name, E-Mail und Rolle
- aktuelle Firma als nicht-technische Kontextkarte
- Mein Profil
- Unternehmenseinstellungen
- Abmelden

## Sprache
Die Sprachauswahl befindet sich nicht mehr in der Dashboard-Topbar.
Sie ist neu unter:
Einstellungen → Mein Profil → Sprache

Die Sprache wird pro AppUser gespeichert.

## Testrollen
Testbenutzer können weiterhin unter Einstellungen → Benutzer & Rollen aktiviert werden.
Damit bleibt der produktive Account-Bereich frei von Demo-/Entwicklerfunktionen.
