# Support Runbook – Binso One

## Ticketstatus
`Neu → In Prüfung → In Bearbeitung → Warten auf Kunde → Gelöst → Geschlossen`

## Diagnose
Diagnose nur verwenden, wenn sie zur Fehleranalyse notwendig ist. Keine Passwörter, Tokens oder Cookies anfordern. Screenshots vor interner Weitergabe auf sensible Inhalte prüfen.

## Temporärer Supportzugriff
- nur für konkretes Ticket
- Begründung erforderlich
- minimaler Scope
- Standarddauer 2 Stunden
- Kunde kann widerrufen
- Ablauf automatisch
- Aktion auditieren

## Priorität
- Kritisch: Plattform-/Sicherheitsausfall oder erheblicher Datenzugriffsverdacht
- Hoch: Kernfunktion blockiert
- Normal: funktionaler Fehler mit Workaround
- Niedrig: Frage, Verbesserung, kosmetisches Problem

## Sicherheitsvorfall
Bei möglichem unberechtigtem Zugriff:
1. Ticket nicht als normale Bedienungsfrage behandeln.
2. Security-Verantwortliche eskalieren.
3. relevante Audit-/Request-IDs sichern.
4. keine Kundendaten in externe Kanäle kopieren.
5. Incident-Prozess starten.
