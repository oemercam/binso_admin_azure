Canonical visual rules:
- PageHeader for route title hierarchy.
- One grouped/inset surface language for metrics, sections and detail panels.
- One radius/spacing rhythm across desktop, mobile and PWA.
- Top-level lists are grouped surfaces; child rows own separators.
- Mobile retains usable width and 44 px touch targets.
- Settings uses the same grouped-list language with a segmented selector.
- Detail pages use the same header, grouped metrics and grouped navigation.
- Auth/error views use the same elevated surface treatment.
