# V81.13 Public Route Visual QA

V81.13 fixes the last false-negative in the cross-page visual QA suite.

The local E2E environment intentionally returns an authenticated demo session. Therefore `/sign-in` and `/admin-access` redirect by design unless their existing `?preview=1` mode is used. The broad public-page visual QA now tests those two pages through that canonical preview mode, while still verifying the real PublicShell, header, footer, typography, overflow and responsive layout.

No production authentication behaviour is changed.
