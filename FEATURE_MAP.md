# Funktionskarte

| Aufgabe | Ort in der App |
|---|---|
| Geschäftslage sehen | Dashboard |
| Kunde erfassen/bearbeiten | Kunden |
| Angebot erstellen, versenden, annehmen/ablehnen | Angebote |
| Aus Angebot Auftrag erzeugen | Angebote → Auftrag erstellen |
| Mandat, Budget und Sonderregeln verwalten | Aufträge → Auftrag öffnen |
| Zeiten erfassen | Zeiterfassung |
| Externen Zeitnachweis hochladen/prüfen | Auftrag → Nachweise / Zeiterfassung |
| Rechnung aus Zeiten erstellen | Rechnungen / Zeiterfassung |
| Rechnung bearbeiten, Vorschau, versenden | Rechnungen |
| Zahlung erfassen | Rechnungen |
| Überfällige Rechnung / Mahnung | Rechnungen / Buchhaltung |
| Lieferantenrechnung / Fremdleistung | Buchhaltung |
| Mitarbeitende, Kosten, Auslastung | Mitarbeitende |
| Absender, Mahnstufen, Lohnlauf, Templates | Einstellungen |
| Hell/Dunkel/System, Push | Einstellungen |

## Rollen

- Mitarbeitende: eigene Aufträge, Zeiten, Nachweise, persönliche Monatsübersicht.
- Buchhaltung: Rechnungen, Zahlungen, Mahnungen, Kreditoren, Lohnfreigaben, Exporte.
- Admin: Kunden, Angebote, Aufträge, Mitarbeitende, Regeln und Einstellungen.
- Inhaber: zusätzlich Margen, Liquidität, Pipeline, Freigaben und Gesamtübersicht.
