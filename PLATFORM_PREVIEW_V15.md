# Binso Admin v15 – Fullscreen Document Preview

## Standard
- Dokumentvorschau belegt immer die gesamte Browser-/PWA-Fläche.
- Globale Topbar, Sidebar und Mobile-Pill liegen unterhalb der Vorschau und sind nicht sichtbar.
- Schliessen erfolgt über ein kompaktes X oben rechts; PDF/Drucken bleibt daneben verfügbar.
- A4-Geometrie bleibt unverändert 210 × 297 mm und wird auf kleineren Viewports als Ganzes skaliert.
- Normale Seitenränder sind zentral standardisiert: Desktop 24 px, Tablet 20 px, Mobile 16 px.
- Safe-Areas von iPhone/PWA werden berücksichtigt.
- Body-Scroll wird während einer Dokumentvorschau gesperrt; nur die Vorschau scrollt.
- Light Mode verwendet das schwarze Binso-Logo, Dark Mode das weisse Logo.
