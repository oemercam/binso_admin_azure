# Binso Admin v18.3 – Information Density Standard

## Grundregel
- Übersicht: maximal 3 Kerninformationen + klare Einstiege.
- Object Hub: kurzer Statusblock + 5–7 Bereiche.
- Arbeitsansicht: nur Informationen der aktuellen Aufgabe.
- Lange Formulare: progressive Abschnitte statt einer Wand aus Feldern.
- Mobile/PWA: Kategorien zuerst, Detail erst nach Auswahl.

## Umgesetzt
- Dashboard Mobile: 3 Kern-KPIs, Heute wichtig, kompakte Bereichseinstiege; Chart/Pipeline/Zahlungslisten nicht mehr gleichzeitig sichtbar.
- Auftragsdetail: Object Hub für Übersicht, Team, Zeiterfassung, Nachweise, Abrechnung und Dokumente; Mobile zeigt immer nur Hub oder ausgewählten Bereich.
- Auftragsregeln: getrennt in Zeiterfassung, Nachweise und Abrechnung.
- Einstellungen Mobile: Apple-Settings-artige Kategorien statt horizontalem Tab-Band.
- Buchhaltung Mobile: Zu-erledigen-Bereich zuerst, nur zwei Kern-KPIs auf den ersten Blick.
- Angebot erstellen/bearbeiten: Stammdaten, Positionen und Texte als progressive Abschnitte.
- Rechnung erstellen/bearbeiten: Quelle, Zeiten, Positionen und Texte als progressive Abschnitte.

## Plattformregeln
- Desktop darf zusätzliche Kontextspalten zeigen.
- Mobile/PWA bleibt task-first und reduziert.
- Keine wichtigen Aktionen werden abgeschnitten; Sticky Actions und Safe Areas bleiben aktiv.
- Native Scrollmechanik, keine erzwungenen Seitenanimationen.
