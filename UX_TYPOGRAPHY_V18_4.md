# Binso Admin v18.4 – Typography & Readability

Central typography system for desktop, mobile and installed PWA.

- Native system UI font stack (SF on Apple, Segoe UI Variable/Segoe UI on Windows, system/Roboto on Android).
- No downloaded web font and no artificial font smoothing.
- Minimum practical UI text sizes increased; row titles and metadata standardized.
- Improved light/dark contrast tokens.
- 16 px inputs on mobile to prevent iOS auto zoom.
- Tabular numerals for financial and KPI values.
- Status colors remain supplemental to text labels.
- PDF/print document typography is isolated from UI overrides.
