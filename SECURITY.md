# Security Policy

Report vulnerabilities through the Binso One Security page and the configured security contact shown there. The dedicated role mailbox is published only after it has been provisioned, permissioned and verified.

Do not open a public GitHub issue containing vulnerability details. Helpful information includes the affected function, reproducible steps, impact, timestamps and a safe proof of concept. Do not include passwords, tokens, customer data or unnecessary personal data.

Binso GmbH does not promise a bug-bounty programme or fixed response time unless separately agreed.

Scope: Binso One, its public web application, supported APIs and directly operated production services. Do not publish exploit details or customer data before remediation has been coordinated.
