# Binso One v1.6.8 — Final Mobile/PWA UX/UI Master Audit

- Mobile/PWA monochrome design contract: light is white/black, dark is black/white; hierarchy uses typography, spacing, borders and dividers.
- Floating pill bottom navigation with safe-area spacing; desktop navigation unchanged.
- Quick Create remains a content-driven bottom sheet; account opens as a compact top panel.
- Global search remains desktop-only; contextual list search remains local.
- Mobile record rendering now suppresses normalized duplicate subtitles and technical local/demo labels.
- Active time tracking is shown globally in a compact header-adjacent indicator only while a timer exists.
- Mobile/PWA toasts are positioned below the safe-area/header instead of above bottom navigation.
- Mobile surfaces, overlays, inputs and ordinary content are flattened to the canonical white/black theme.
- Existing permission, authentication, navigation, timer and business logic are retained.
- New master audit self-check guards the central UX contracts.
