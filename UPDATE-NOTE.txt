Binso Admin V20 – vollständiger aktueller Quellstand

Dieser Stand enthält die zuletzt implementierten Business-Workflow-, Architektur- und PWA-Fixes.

WICHTIG beim Aktualisieren eines bestehenden lokalen Repositories:
- Vorhandene package-lock.json behalten. Sie ist in diesem Archiv nicht enthalten.
- node_modules und .next nicht aus diesem Archiv übernehmen; lokal neu erzeugen.
- Dateien aus diesem Archiv über das bestehende Projekt kopieren/ersetzen.

Danach prüfen:
  npm ci
  npm run typecheck
  npm run lint
  npm run architecture:check
  npm run build
