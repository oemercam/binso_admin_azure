# V70.4 – Landing Light Brand

## Scope

Only the public landing page presentation is changed. The authenticated application UI is intentionally untouched.

## Rules

- Landing page is always light: white background, black primary text.
- The canonical original Binso logo asset (`/brand/logo-black.svg`) is used through `BinsoLogo`.
- Colour is reserved for product visuals, process graphics, charts and selected supporting cards.
- The landing page does not inherit the application dark theme.
- Existing app navigation, dashboard and module UI are unchanged.

## Visual structure

1. Product hero with desktop and mobile application preview.
2. Four compact benefit cards.
3. Product proof / dashboard visual.
4. Feature stories.
5. End-to-end business process.
6. Guided onboarding.
7. Security, pricing, FAQ and final CTA.
