# V70.2 – Public Visual Upgrade

## Ziel
Die öffentliche Binso-One-Seite zeigt das Produkt visuell und erklärt zentrale Geschäftsabläufe ohne lange Textblöcke. Der Cookie-Consent folgt demselben Design-System.

## Umsetzung
- Produktvorschau als responsive Desktop- und Mobile-App-Grafik direkt aus UI-Komponenten.
- Geschäftsablauf Kunde → Angebot → Auftrag → Zeit und Leistung → Rechnung → Zahlung als responsive Prozessgrafik.
- Funktionsbereiche als visuelle Karten mit eigenem Icon und UI-Motiv.
- Onboarding als visuelle Fortschrittsdarstellung.
- Cookie-Consent neu aufgebaut: kompakter Ersthinweis, gleichwertige Auswahlmöglichkeiten und separates Einstellungs-Panel.
- Mobile Cookie-Einstellungen werden als Bottom Sheet dargestellt.
- Keine externen Bild-, Icon- oder UI-Bibliotheken nötig; Darstellungen bleiben leichtgewichtig und im Binso-One-Design-System.

## Qualitätsregeln
- Keine hardcodierten Markenfarben ausser den zentralen Design-Tokens.
- Keine parallele öffentliche Typografie.
- Produktgrafiken enthalten nur Beispieldaten und keine echten Kunden- oder Personendaten.
- `prefers-reduced-motion` und bestehende Dark-Mode-Tokens bleiben erhalten.
