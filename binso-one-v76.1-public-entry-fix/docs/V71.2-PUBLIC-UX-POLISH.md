# V71.2 Public UX polish

## Scope

- All public marketing pages use the fixed light theme.
- Public navigation includes a Startseite entry.
- Mobile navigation uses an animated hamburger-to-close transition and animated menu panel.
- Pricing cards use touch swipe on Mobile/PWA with a visible next-card preview and compact position indicator.
- Landing onboarding is redesigned as a connected setup experience rather than a basic step list.
- Landing security is redesigned as a visual security architecture section.
- The dedicated security page follows the same spacious public design language.
- Registration entry keeps the existing flow but receives a more deliberate setup visual.

## Boundaries

The authenticated Binso One application, tenant/RBAC foundation, database model and platform operations are not changed by this release.
