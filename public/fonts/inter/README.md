# Inter, locally hosted

Unmodified `inter-latin-wght-normal.woff2` from
`@fontsource-variable/inter@5.3.0` (Inter v20). Copyright and SIL Open Font
License 1.1 are preserved in LICENSE.txt. Latin includes the accents used by
German, French, Italian and English; other scripts retain the system fallback.

SHA256: `3100e775e8616cd2611beecfa23a4263d7037586789b43f035236a2e6fbd4c62`.
48,256 bytes; variable normal weights 100–900. The existing theme owner defines
the only runtime face. No CDN, browser request to Fontsource, tracking or font
package runtime is introduced. `font-display: optional` avoids a late font swap
on slow first loads; the existing system-font stack remains valid offline.
