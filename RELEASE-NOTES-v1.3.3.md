# Binso One v1.3.3

## Mobile- und PWA-Navigation

- Mobile Marketing-Navigation öffnet jetzt von oben nach unten über die komplette Fläche unterhalb des Headers.
- Header, Logo und Hamburger/X bleiben beim Öffnen und Schliessen pixelstabil an derselben Position.
- Hamburger-Linien animieren weiterhin direkt zum X; kein zusätzlicher Close-Button verschiebt das Layout.
- Mobile Marketing-Seiten verwenden einen festen Header mit korrektem Content-Offset und starten bei Navigation immer am Seitenanfang.
- Menü sperrt den Hintergrund-Scroll und hat einen eigenen, Safe-Area-konformen Scrollbereich.
- Escape-Taste schliesst das Menü; beim Öffnen wird der erste Navigationslink fokussiert.
- Navigation berücksichtigt iOS/Android/PWA Safe Areas und Reduced Motion.
